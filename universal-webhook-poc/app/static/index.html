A) FlightHub2 三件套（热更新）

Worker 每条消息从 Redis 读取配置，保存后立即生效。

C) 三件套提取器

粘贴 HTTP headers / curl / JSON 片段，提取后一键应用。
{}

B) 字段映射配置（JSONPath）

每行定义一个字段：从 webhook_event 取值、类型转换后注入模板。

入站鉴权 中间件 Token

每 Source 独立入站 Token

enabled=false 时鉴权完全关闭，任何请求均放行（无需 token）。

调用示例

鉴权开启时：
curl -X POST http://127.0.0.1:8000/webhook \
  -H 'Content-Type: application/json' \
  -H 'X-MW-Token: <token>' \
  -d '{"source":"flighthub2","webhook_event":{...}}'
鉴权关闭时（enabled=false）：
curl -X POST http://127.0.0.1:8000/webhook \
  -H 'Content-Type: application/json' \
  -d '{"source":"flighthub2","webhook_event":{...}}'

Redis 热更新

redis-cli set uw:srcauth:flighthub2 \
  '{"enabled":true,"mode":"static_token",
    "header_name":"X-MW-Token",
    "token":"NEW_TOKEN"}'
